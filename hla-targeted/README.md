# Targeted C4/RCCX typing

The frozen targeted assay has been evaluated on all 24 held-out donors. It recovers 24/24 total-copy labels and 21/24 full structural pairs, versus 22/24 structural pairs with the old sketch. The dedicated C4Investigator comparison is complete: native total-copy calls match 14/24, and the separately calibrated total-copy result is 24/24. See [the full report](REPORT.md) and [the calibration supplement](COMPARATOR_CALIBRATION.md), [structural error examples](STRUCTURAL_ERRORS.md), and [noncanonical motif candidates](NONCANONICAL_CANDIDATES.md).

We are testing C4 A/B diagnostic sites, long/short HERV insertion junctions, and module-start context probes, alongside the published C4Investigator caller. Module-start context probes are not established structural-variant breakpoints. Dosage evidence must be distinguished from chromosome phase and module order.

The previous 106 donors are development data only. A fixed set of 24 previously untested donors was selected before examining their read-based typing results; all their recorded families are excluded from marker discovery and reference paths. These donors are drawn from the existing assembly panel, not an independent external cohort. Public MHC-recruited WGS reads have been retrieved for all 24. Selection and source URLs are recorded in `source/validation_selection.json` and `source/validation_donors.tsv`.

Development references contain 543 haplotypes and 1,090 annotated C4 genes. Diagnostic-site auditing found three noncanonical A-like motifs; these are candidates for further investigation, not validated novel alleles. All 299 targeted probes passed a full-training-MHC specificity audit, and the fragment counter passed synthetic contract tests. Development measurements, dosage calibration, model freezing and targeted fresh-donor evaluation are complete. The post-freeze audit of 91 validation C4 genes agrees with all inherited A/B and long/short annotations. All comparator jobs and final completion checks have passed. See `PROTOCOL.md` for endpoints and limitations.

## Reproduction

The scripts use the local cached inputs documented in `../HLA_RESULTS.md` and DDBJ paths in the Slurm scripts. Run `select_validation.py`, `prepare_targets.py`, `align_targets.sbatch`, `build_markers.py`, `prepare_profiles.py`, and `compile_background.sbatch`; validate marker specificity before running `measure.sbatch`. Install and run the dedicated comparator using `install.sbatch` and `c4investigator.sbatch`. Freeze the final model before inspecting fresh-donor results.

The third-party C4Investigator checkout is excluded from Git. Clone https://github.com/Hollenbach-lab/C4Investigator into `source/C4Investigator` and use the commit in `source/tool_version.json`. Large reconstructed FASTA, PAF and NumPy files, binaries and read caches are excluded and can be regenerated. The archived preprint is `literature/C4Investigator_preprint.xml`; the journal article is DOI 10.1111/tan.15273.

Canonical repository: https://github.com/leechuck/pangenome-bh26

## Replay the derived-input analysis

`source/inference_inputs.tar.gz` bundles the training profile matrix, full-training-MHC background counts, and fragment/depth measurements for the 106 development and 24 validation donors. It contains derived measurements, not raw sequencing reads. Verify and extract it from `source/`:

```bash
cd hla-targeted/source
sha256sum -c inference_inputs.sha256
tar -xzf inference_inputs.tar.gz
cd ..
python3 infer.py --cohort validation
python3 evaluate.py --cohort validation
python3 case_analysis.py
python3 structural_error_details.py
```

Python requires NumPy; sequence preparation/auditing additionally requires Biopython, and figure generation requires Matplotlib. The comparator package versions are recorded in `source/c4_environment.json`; its upstream commit is in `source/tool_version.json`.

All native-comparator CSV files are included. The final tables count all 24 attempted validation donors, including abstentions. Preserve the archived freeze when replaying this experiment. Recreating the entire sequence-level audit and checking every frozen input hash additionally requires the excluded training gene FASTA/PAF, module contexts and reference FASTA, regenerated by the preparation/alignment scripts from the original dataset.

## Evidence boundaries

All 106 previously examined donors are development data. The 24 validation families were excluded from marker discovery and reference paths, but their assemblies contributed to the original graph construction. This is new-donor read validation within that panel, not external-cohort validation. Exact signature ranking is imputation, not proof of physical phase; every validation donor retains multiple dosage-compatible structures. Native C4Investigator outputs are retained, with a separately declared pilot-only total-dosage calibration as a fairness diagnostic.

The inherited marker vocabulary was global; retained inherited features are independently supported by training families and fixed sequence-only sampling. See [the provenance audit](MARKER_PROVENANCE.md) for the distinction between vocabulary, feature eligibility and candidate-path exclusion.

After restoring the derived inputs, `comparator_total_calibration.py` reproduces the pilot-only calibration supplement. `check_results.py` verifies all frozen hashes and requires the original sequence-level inputs described above. `report.py` followed by `finalize_report.py` regenerates the final report and PNG/PDF figure. `MARKER_PROVENANCE.md` documents the inherited sketch audit; `COMPLETION_AUDIT.md` maps requirements to evidence. All 201 submitted Slurm tasks completed successfully, as recorded in `source/job_completion.tsv`.

For the extra specificity audit, verify and extract `source/validation_background_counts.tar.gz` within `source/`, reconstruct validation C4 sequences with `audit_validation_genes.py prepare`, then run `audit_validation_specificity.py`. These post-evaluation controls change no caller predictions. `source/python_versions.json` records the local analysis environment.
