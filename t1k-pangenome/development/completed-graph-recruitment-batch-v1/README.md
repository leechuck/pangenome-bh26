# Completed balanced graph recruitment comparison

All eight predefined development donors completed every condition. No held-out
validation outcomes were used. Each graph condition unions graph-recruited read
pairs with native T1K candidates, then runs unchanged T1K against genomic IPD.
It does not combine native and graph genotype likelihoods.

| Method | Two-field /63 | Four-field /47 |
|---|---:|---:|
| Original T1K | 63 | 21 |
| Genomic IPD | 62 | 41 |
| All pre-recruited HLA reads | 61 | 41 |
| HPRC sampled | 61 | 40 |
| HPRC unsampled | 61 | 40 |
| HPRC + Asian sampled | 61 | 41 |
| HPRC + Asian unsampled | 60 | 40 |

These small development differences do not establish general inferiority, but
there is no additional gain over genomic IPD from these recruitment conditions.
Per-donor directories retain the scorer's verified input/output provenance.
The graph pair-refinement comparison is archived separately.
