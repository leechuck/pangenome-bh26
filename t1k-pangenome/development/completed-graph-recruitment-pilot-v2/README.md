# Complete HG00658 recruitment pilot

Every genomic-IPD condition scored 8/8 eligible two-field genotypes and 5/5
exact four-field genotypes: native candidates, all initially recruited reads,
and all four graph conditions. Original T1K scored 8/8 and 2/5. Native-only
reconstruction passed byte-identical genotype parity.

Supplying all 738,921 pairs rather than 35,192 native candidate pairs did not
change this donor's accuracy. Graph unions used 48,261–53,109 pairs and also did
not improve on the genomic-IPD control. This is one exposed development donor;
no graph-specific or independent accuracy benefit is established. This complete
snapshot supersedes v1, which excluded the then-running all-read condition.
