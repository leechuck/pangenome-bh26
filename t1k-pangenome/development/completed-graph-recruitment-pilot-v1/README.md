# Graph recruitment pilot: HG00658

All four graph conditions completed: HPRC and HPRC plus Asian, each with path
selection enabled and disabled. Every condition scored 8/8 eligible two-field
and 5/5 exact four-field genotypes. Full genomic IPD alone also scored 8/8 and
5/5; original T1K scored 8/8 and 2/5. Native-only reconstruction preserved the
full genomic IPD genotype file byte-for-byte.

There is no incremental graph accuracy gain on this donor. This is an exposed
development pilot with only five eligible four-field genotypes, not independent
validation. The all-read arm is still running and is excluded from this completed
snapshot. A fixed eight-donor balanced expansion is running separately.
