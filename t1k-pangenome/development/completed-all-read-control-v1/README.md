# Completed all-read control: 64 development donors

| Method | Two-field | Four-field |
|---|---:|---:|
| Original T1K | 495/509 | 163/323 |
| Full genomic IPD, native read extraction | 494/509 | 285/323 |
| Full genomic IPD, all recruited reads | 493/509 | 285/323 |

All 64 donors completed. Bypassing candidate extraction provides no net four-field
improvement: one gain and one loss. At two fields, two gains and three losses yield
a net one-call difference versus genomic IPD with ordinary extraction. These small
point differences should not be overstated. All initially recruited pairs are
included, rather than whole-genome reads. Input/reference checks and allele
inference are identical to the completed pilot.

Paired family intervals, ancestry summaries, donor/gene scores and run provenance
are archived here. These are exposed development results. The large gain over
original T1K remains attributable to genomic-reference information, not graph use.
