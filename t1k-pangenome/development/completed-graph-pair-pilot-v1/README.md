# Real-data graph pair refinement pilot

All four HG00658 conditions completed without changing the native genomic-IPD
calls: 8/8 eligible two-field and 5/5 exact four-field genotypes. Missing native
alleles, unknown competing paths or tied graph pairs retain native fallback.
The additive unsampled graph agrees with the native pair at A, C, DPB1 and DQA1;
DQB1 retains fallback because its best graph pair includes an unlabelled path.

These are development integration results, not an incremental improvement claim.
Per-gene candidate score differences are uncalibrated; the fragment-variation
count measures variation across all candidates, not necessarily only the native
and proposed pair. The same version is being characterized on the fixed seven
additional development donors. Reserved outcomes remain unscored.
